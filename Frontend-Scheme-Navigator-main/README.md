## 🧭 About the Platform

Government schemes can feel like a complex maze with fragmented information, dense gazettes, and unclear eligibility.

**SchemeNavigator** acts as a navigational compass between citizens and public welfare programs:
- **No scheme knowledge needed**: Start with *"Tell us about yourself"*.
- **Explainable Match Scoring**: Deterministic rule-based compatibility engine (0–100%) with criteria breakdown.
- **Plain Language & Checklists**: Clear benefit values, required documents, and step-by-step application guides.
- **Verified Official Redirection**: Direct routing to authentic `.gov.in` / `.nic.in` portals with safety pre-flight checks.

---

## ✨ Key Features

- **Compass & Satellite Orbit Visual**: Interactive visual identity representing discovery and direction.
- **6-Step Eligibility Survey (`/survey`)**: Personal, Location (States & Districts), Social Background (Categories, Divyangjan, BPL), Occupation, Household Income, and Review.
- **Analysis Screen (`/analyzing`)**: Transparent multi-step evaluation animation with celebratory transition.
- **Personalized Recommendations (`/recommendations`)**: Ranked schemes with match percentage badges, filter pills, and search.
- **Scheme Details (`/schemes/:id`)**: Plain-language overview, key benefits, eligibility criteria checklist, required documents checklist, and application roadmap.
- **User Dashboard & Tracker (`/dashboard`)**: Track application milestones (*Exploring*, *Documents Needed*, *Ready to Apply*, *Applied Externally*, *Completed*), manage saved schemes, and recalibrate profile.
- **AI Scheme Advisor (`/assistant`)**: Grounded conversational assistant answering natural language questions.
- **National Scheme Directory (`/explore`)**: Full-text search and filtering across Central and State programs.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite + TypeScript
- **Styling**: Tailwind CSS v4 + Custom Theme Design Tokens
- **Icons**: Lucide React
- **Animations**: Framer Motion + Canvas Confetti
- **Routing**: React Router v7
- **Persistence**: LocalStorage Browser State Service

## 🚀 Quick Start

### 1. Clone Repository
```bash
git clone https://github.com/aidivi265/Frontend-Scheme-Navigator.git
cd Frontend-Scheme-Navigator
```


### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
